**Pizza Sales Analysis — SQL + Excel Dashboard**

This project is an end-to-end analysis of pizza sales using SQL for data extraction and Excel for visualization.
The goal was to understand revenue patterns, customer behavior, top-performing products, and operational trends through data-driven insights.

**Project Overview**

The dataset contains four related tables:

orders

order_details

pizzas

pizza_types

SQL was used to clean and analyze the data, calculate revenue, quantities, category contributions, and other business metrics.
These results were then visualized in an interactive Excel dashboard using KPIs, charts, slicers, and pivot tables.

**Objectives**

Analyze overall sales trends

Identify best-selling pizzas and categories

Understand customer ordering patterns

Calculate revenue contribution by pizza types

Build an interactive dashboard for business insights

Provide recommendations based on the findings

**Tools Used**

SQL (MySQL Workbench) – joins, aggregations, CTEs, window functions

Excel – dashboard, pivot tables, charts, slicers

GitHub – project documentation and hosting

**SQL Analysis Performed**
1. Data Exploration

Total orders

Total revenue

Highest priced pizza

Most common pizza size

2. Sales Analysis

Top 5 most ordered pizzas

Hour-wise distribution of orders

Top 3 pizzas by revenue

3. Operational Insights

Percentage revenue contribution by pizza type

Cumulative revenue over time

Average pizzas ordered per day

4. Category Analysis

Total quantity ordered per category

Category-wise distribution

Top 3 pizzas by revenue within each category

**Key Insights (Example Values)**

Total Orders: 48,620

Total Revenue: 817,860.05

Most Popular Pizza Size: S

Highest Priced Pizza: The Greek Pizza – 35.95

**Recommendations**

Increase stock for top-selling pizzas to avoid shortages

Re-evaluate low-performing pizzas to reduce waste

Run promotions during peak ordering hours

Introduce new variants of high-demand pizzas

Allocate staff more efficiently during busy hours

Use category and size insights to improve inventory planning

**Conclusion**

By combining SQL analysis with an interactive Excel dashboard, this project transforms raw sales data into practical insights that support better business decisions.
